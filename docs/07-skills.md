## Descargable seleccionada

[frontend-design](https://skills.sh/anthropics/skills/frontend-design), repositorio [anthropics/skills](https://github.com/anthropics/skills), [fuente oficial](https://raw.githubusercontent.com/anthropics/skills/main/skills/frontend-design/SKILL.md).

La consulta mostró aproximadamente 1.1 M instalaciones y 187 k estrellas del repositorio. Señales de adopción, no garantía. Se revisó contenido y pertinencia.

Instalación opcional desde Mac:

    npx skills add anthropics/skills --skill frontend-design

Elegir alcance local y agente; revisar licencia/archivos y registrar versión/commit. No instalar todo el paquete ni depender de rutas Windows.

No se requieren skills React para Astro estático. No se generan logos/fotos. Apple-design puede evaluarse si aparecen interacciones que lo justifiquen. Los contratos permiten continuar sin copiar skills privadas entre máquinas.
